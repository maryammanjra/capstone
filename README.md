# Autonomous Shopping Cart Group - Team 27 
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
## Code Layout 
- All implemented functions and helper code placed in **source** directory
- All necessary user-defined header files in **drivers** directory
- For board support packages - use the default ones provided in MCUXpresso when creating an empty C/C++ project
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
## Naming Conventions
- Please use the following naming conventions: use underscores to separate words, use lowercases for all variable names EXCEPT macros and constant definitions
- Similarly name all files in the same convention - mark your main code with main.c even if MCUXpresso names it otherwise
- For other stylistic concerns i.e indents, formatting if-else statements etc. please try your best to follow the standards set out here: [C Coding Style](https://users.ece.cmu.edu/~eno/coding/CCodingStandard.html)
## Contributing Guidelines 
- Please create your own branch and name it something meaningful to make it easy for us to track down for example, "gps-ir-motor" this makes it easy for us to track down which hardware we've
  integrated in this iteration
